<h2 style="text-align: center;" id="blog-studio-heading-0">1. Jev?</h2>

<p style="text-align: center;">Jev는 '이 상황을 어떻게 판단할지?'를 빠르게 결정해주는 decision model입니다.</p><p style="text-align: center;"><strong>TypeSafe AI</strong>가 2026년 9월에 공개했으며, 회사는 이런 판단에 특화된 모델을 <strong>System One</strong> 모델이라고 부릅니다.</p>

<h3 style="text-align: center;" id="typesafe-ai">1.1. TypeSafe AI?</h3>

<p style="text-align: center;"><strong><span style="font-family: sans-serif; font-size: 16px; font-weight: 500; margin: 0px; text-decoration: none; border-bottom: 0px rgb(0, 29, 53);" data-subtree="aimfl,mfl">TypeSafe AI는 인간과의 대화 대신 소프트웨어 내부의 자동화된 의사결정을 위해</span></strong></p><p style="text-align: center;"><strong><span style="font-family: sans-serif; font-size: 16px; font-weight: 500; margin: 0px; text-decoration: none; border-bottom: 0px rgb(0, 29, 53);" data-subtree="aimfl,mfl">설계된 Machine-native 지능 인프라를 개발하는 AI 연구소입니다.</span></strong></p><p style="text-align: center;">OpenAI에서 ChatGPT의 핵심 기술인 RLHF(인간 피드백 기반 강화학습)를 주도했던</p><p style="text-align: center;">디오고 알메이다(Diogo Almeida) 등이 공동 창업했으며, 실리콘밸리에서 가장 뜨거운 주목을 받는 스타트업 중 하나입니다.</p><p style="text-align: center;">최근 앤드리슨 호로위츠(a16z)와 세코이아 캐피탈 등으로부터 약 10조 원 이상의 기업 가치를 인정받으며 대규모 투자를 유치했습니다.</p><p style="text-align: center;">뭔가 대단한 것을 개발한 것 같습니다. 그래서 이런 기업을 앞으로 더 잘되지 않을까?라는 생각을 가졌지만 시장에 떠도는 풍문으로는 그렇지 않은 것 같습니다.</p><p style="text-align: center;">ChatGPT, Claude와 같이 대단한 모델을 내놓으며 그 자리를 철옹성같이 지키는 기업이 가지는 특징이 있습니다.</p><p style="text-align: center;"><strong>"독점적인 학습 데이터를 가지며, 학습 과정이 얼마나 재현하기 어려운가?"</strong></p><p style="text-align: center;">그에 반해, Jev는 그렇지 않습니다.</p><p style="text-align: center;">전체 알고리즘을 공개하지 않았지만,</p><p style="text-align: center;">벌써 open source로 github에도 학습법을 추측하여 만든 프로젝트들이 무수히 나오고 있습니다.</p><p style="text-align: center;">이런 학습법을 OpenAI가 이용해 더 우수한 모델을 만들면 결과는 다들 아실것입니다.</p><p style="text-align: center;">창작물은 인정받았지만 돈으로 이어지지 못할 수 있다는 현실이 냉혹한 것 같습니다.</p>

<h3 style="text-align: center;" id="system-one">1.2. System One?</h3>

<p style="text-align: center;">System 1(one)이란 "주어진 상황과 명시된 질문을 평가해,</p><p style="text-align: center;">프로그램이 바로 사용할 수 있는 제한된 형태의 판단과 확률을 빠르게 반환하도록 설계한 AI"입니다.</p><p style="text-align: center;">기존 LLM은 System 2라고 생각하시면 됩니다.</p><p style="text-align: center;">답을 낼때 오래 생각하고 난뒤에 결정을 내리기 때문이고</p><p style="text-align: center;">System 1은 거의 생각과 동시에 결정을 내리는 구조로 생각하시면 됩니다.</p><p style="text-align: center;"></p><p style="text-align: center;"></p>

### 2.1. State, Questions

State는 ‘판단할 자료’, Questions는 ‘그 자료를 보고 무엇을 판단할지’입니다. 시험에 비유하면 State는 지문이나 사진이고, Questions는 문제와 답안 형식입니다.

**State:**

* 문장 하나: 일반 텍스트 입력
* 여러 정보 함께 전달: JSON
* 사진: 이미지 업로드

```json
{
  "message": "어제 받은 머그컵이 깨져 있어요. 교환하고 싶습니다.",
  "policy": "배송 중 파손된 상품은 수령 후 7일 이내 교환 가능합니다."
}
```

state는 어떠한 형태든 가능합니다.

**Questions:** 4가지 방법이 존재.

```json
{
  # noul: 참인지 거짓인지 판단용
  "person_present": {
    "type": "noul",
    "instructions": "사진에 식별 가능한 사람이 한 명 이상 보이나요?"
  },
  # choice: criteria의 선택지를 고르게 하기
  "scene_type": {
    "type": "choice",
    "instructions": "사진에 보이는 장면은 어떤 공간인가요?",
    "criteria": {
      "indoor": "주된 장면이 건물 내부의 실내 공간이다.",
      "outdoor": "주된 장면이 건물 밖의 실외 공간이다.",
      "mixed_or_unclear": "실내와 실외가 함께 나타나 주된 공간을 정하기 어렵거나, 사진만으로 판단하기 어렵다."
    }
  },
  # score: criteria를 기준으로 점수를 출력
  "crowding_level": {
    "type": "score",
    "instructions": "사진 속 사람들이 얼마나 밀집해 있나요? 사람 사이의 간격을 기준으로 평가하세요.",
    "criteria": [
      "사람이 없다.",
      "사람이 한 명이거나, 사람들이 대체로 떨어져 있어 여유롭다.",
      "여러 사람이 가까이 모여 있어 다소 붐빈다.",
      "대부분의 사람이 서로 매우 가까이 붙어 있어 빽빽하다."
    ]
  },
  # 이미지의 box를 출력
  "leftmost_person": {
    "type": "box",
    "instructions": "사진에서 가장 왼쪽에 있는 사람의 보이는 신체 전체를 둘러싸는 사각형을 찾으세요. 들고 있는 우산은 대상에서 제외하세요."
  }
}
```

### 해보기

저는 사실 텍스트보다 이미지가 궁금해서 이미지로 먼저 해보았습니다. 사람이 많은 경우 정확하게 측정하는지에 대한 예시입니다.

왜 자꾸 13명이라 하는지 이걸로 해석 가능할수도 있겠어요.
![image](/assets/images/posts/studio-093a1f4125c14aa4bb6bff0c8c332954/image-f59a09eff34be1bf.webp)

다 왼쪽에서 첫번째 사람만 가리키네요.. 아직 이 부분은 발전해야할 여지가 많아보입니다. 이런게 잘 되어야 대 Agentic AI 시대에 사용할만한 곳이 많을 텐데요. 그래도 이미지로부터 내가 원하는 결과를 학습없이 바로바로 빠른 latency로 얻을 수 있다는건 정말 편리해보입니다.

그리고 보셨겠지만, 가장 신기한 것 중 하나는 JSON에 question을 여러개 넣어도 병렬처리로 한번에 결과가 나온다고 합니다! 이게 AR (Auto Regressive) 구조인 LLM과 가장 큰 차이인 것 같아요.

## 소감

오늘은 요새 말 많은 Jev를 사용해보았습니다. 빠른 실행 속도에 놀랐지만, 초기 모델이니 만큼 성능은 부족해보였습니다. 그도 그럴것인게 Open source인 Qwen3.5-27B 모델을 Jev로 파인튜닝한 모델이 github에 release 됐는데, 성능을 추월했더군요. 지금은 Frontier 급의 성능을 기대하기 힘들지만, 성능 좋은 모델이 나오면 게임, 로봇, 주식 등의 분야에서 엄청나게 잘 쓰일 것 같습니다. 연구적으로도 할게 많아보여요. 특히, 주식이나 코인 단타는 대규모 데이터로 트레이드하면 잘하지 않을까요? 그저 궁금하네요.

다음번에는 OpenSource Jev 모델들은 어떻게 학습을 했는지 가져올 것 같습니다.

감사합니다.
